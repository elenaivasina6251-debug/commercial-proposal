# Публичная интерактивная страница КП

Это самостоятельный сайт для GitHub Pages: клиент может выбрать ООО или ИП, изменить количество операций для предварительной оценки и распечатать КП в PDF.

Публикуется из корня отдельного репозитория GitHub. Не добавляйте в него внутренние документы и данные клиентов из родительской папки `КП`.

В этой версии намеренно нет пароля, панели сотрудника, себестоимости и калькулятора маржи. Всё, что попадает в HTML/JavaScript публичной страницы, доступно каждому посетителю.
